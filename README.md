# 2D Graphics Modeler

A Qt based 2D graphics application demonstrating object oriented design principles and shape abstraction for CS1C.

## About

This project is a comprehensive 2D graphics modeler built with C++ and Qt that showcases advanced object oriented programming concepts including polymorphism, inheritance, and abstraction. The application allows users to create, manipulate, and render various 2D shapes through an intuitive GUI interface.

The project emphasizes clean abstraction through a unified shape hierarchy, where different geometric primitives (lines, rectangles, ellipses, polygons, polylines, and text) inherit from a common base class, enabling polymorphic rendering and manipulation.

## Features

- **Shape Creation**: Draw and add multiple 2D shapes including lines, rectangles, ellipses, polygons, polylines, and text
- **Shape Manipulation**: Move, modify, and manage shapes on the canvas
- **User Authentication**: Login system with admin and guest roles
- **File Persistence**: Load and save shapes from/to text files using a custom parser
- **Testimonials System**: View and manage user testimonials
- **About Us**: Information page about Team Cloud

## Technologies

- **Language**: C++
- **Framework**: Qt (GUI framework)
- **Build System**: CMake & QMake
- **Design Patterns**: Abstraction, Inheritance, Polymorphism
- **Data Structures**: Custom vector implementation

## Architecture Highlights

The project demonstrates strong OOP principles:
- Abstract base class for unified shape interface
- Polymorphic rendering through virtual functions
- Encapsulation of shape properties and behaviors
- File I/O abstraction through parser classes
